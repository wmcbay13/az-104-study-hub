# AZ-104 Study Hub

Self-contained static study hub for the Microsoft Azure Administrator (AZ-104) certification.

Open `index.html` directly in a browser, or serve this directory locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

The hub includes 30- and 90-day study plans, a 90-question practice bank, advanced multi-constraint scenarios, a filterable Flashcards section with reusable AZ-104 diagrams, visual case studies with diagrams and tables, dark mode, official Azure service icons, common exam traps, progress saved in browser `localStorage`, and links to Microsoft Learn documentation. The question bank is original practice content and is not an actual Microsoft exam bank.

The service icons come from Microsoft’s [Azure Architecture Center icon set](https://learn.microsoft.com/en-us/azure/architecture/icons/) and are used for training/diagram purposes under Microsoft’s published icon terms.

Primary source: [Microsoft AZ-104 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-104).
